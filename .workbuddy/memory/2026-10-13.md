## 经验
- README 里最该写的不是「做成了什么」，而是「**哪些看似合理的做法被证伪了**」。
  这类负面结论的读者价值往往高于成功案例。
- 发布前务必核对 README 中的每个数字与实测输出是否一致。
  这次就发现断言数和削减率两处过期。
